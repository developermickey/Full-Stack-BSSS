<a name="challenges-faced--solutions"></a>
## 💡 CHALLENGES FACED & SOLUTIONS

| Challenge | Solution | Day(s) |
|-----------|----------|--------|
| **HTML Validation Errors** | Used W3C Validator iteratively; fixed nesting, missing alt tags, duplicate IDs | 1-6 |
| **CSS Box Model Confusion** | Adopted `box-sizing: border-box` globally; understood padding/border inclusion | 7-9 |
| **Flexbox Axis Confusion** | Created visual diagrams; practiced with Flexbox Froggy game | 9 |
| **Mobile Menu Toggle** | Combined CSS `display: none` + JS class toggle; used media queries | 22 |
| **localStorage Data Persistence** | JSON.parse/stringify; initialized with fallback `|| []` | 24 |
| **Inline Editing UX** | State variable `editingId`; conditional rendering in `renderNotes()` | 24 |
| **XSS Vulnerability** | Implemented `escapeHtml()` using `document.createElement('div').textContent` | 24 |
| **Dynamic Event Handlers** | Attached functions to `window` object for inline `onclick` | 24 |
| **Responsive Breakpoints** | Used `@media (max-width: 768px)` and `@media (max-width: 480px)` | 8, 9, 22, 24 |
