# Beginner HTML Practice Tasks

## Topics Covered

You already know:

- Video tag
- Audio tag
- Lists
- Images
- Semantic HTML tags

Complete the following 5 beginner-level HTML tasks.

---

## Task 1: Personal Profile

Create an HTML page for a personal profile.

### Requirements

- Add your name using an `<h1>` tag.
- Add a profile image using the `<img>` tag.
- Add a short introduction using a `<p>` tag.
- Add an unordered list containing 3 hobbies.
- Add a link to your favorite website using the `<a>` tag.

### Bonus

Use semantic HTML such as `<header>`, `<main>`, and `<footer>`.

---

## Task 2: Simple Blog Article

Create a simple blog article page using semantic HTML.

### Requirements

Use:

- `<header>`
- `<main>`
- `<article>`
- `<footer>`

Inside the article:

- Add a blog title.
- Add an image.
- Add at least 2 paragraphs.
- Add a list containing 3 important points.
- Add the author's name.

### Bonus

Add a `<time>` element for the publication date.

---

## Task 3: My Media Page

Create a page called **My Media**.

### Requirements

- Add a heading called "My Media".
- Add one video using the `<video>` tag.
- Add video controls.
- Add one audio file using the `<audio>` tag.
- Add audio controls.
- Add a heading and short description for both the video and audio.
- Organize the content using semantic HTML.

### Bonus

Use `<section>` for the video and audio areas.

---

## Task 4: Restaurant Menu

Create a restaurant menu page.

### Requirements

- Add the restaurant name as the main heading.
- Create 3 sections:
  - Starters
  - Main Course
  - Desserts
- Use an unordered list for each category.
- Add at least 3 food items in each category.
- Add a food/restaurant image.
- Add contact information in the footer.

### Bonus

Use semantic tags such as:

- `<header>`
- `<main>`
- `<section>`
- `<footer>`

---

## Task 5: News Article Page

Create a simple news website layout using semantic HTML.

### Requirements

Create the following structure:

- `<header>` — Website name
- `<nav>` — At least 3 navigation links
- `<main>` — Main content area
- `<article>` — News article
- `<aside>` — Related news
- `<footer>` — Copyright information

Inside the article:

- Add a news headline.
- Add an image.
- Add at least 2 paragraphs.
- Add a list containing 3 important points.
- Add the author's name and publication date.

### Bonus

Use `<time>` for the publication date.

---

# Challenge Rules

Try to complete all 5 tasks using **HTML only**.

Do not use:

- CSS
- JavaScript
- Bootstrap
- Tailwind CSS

Focus on writing clean and properly structured HTML.

## Submission Checklist

Before submitting your work, check:

- [ ] All 5 tasks are completed.
- [ ] HTML tags are properly opened and closed.
- [ ] Images have `alt` attributes.
- [ ] Video has `controls`.
- [ ] Audio has `controls`.
- [ ] Semantic HTML tags are used correctly.
- [ ] Links work correctly.
- [ ] Lists are properly structured.
- [ ] The HTML document has `<!DOCTYPE html>`.
- [ ] The page contains `<html>`, `<head>`, and `<body>`.

## Goal

By completing these tasks, you should become comfortable with:

**Images → Lists → Audio → Video → Links → Semantic HTML → Page Structure**
